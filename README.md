# Bigger Shulker Boxes

**Bigger Shulker Boxes** expands vanilla Minecraft Shulker Box container storage from 27 slots (3 rows) to 54 slots (6 rows) - doubling portable inventory capacity to match a double chest!

---

## Features

- **Double Capacity**: Every Shulker Box holds 54 slots (6 rows).
- **Vanilla Equivalent**: Uses the native 6-row container UI.
- **Hopper & Automation Support**: Hoppers and droppers interact seamlessly across all 54 slots.
- **Safe Item Persistence**: All 54 slots are saved directly into the Shulker Box item data.
- **Singleplayer & Server-Side**: Works on dedicated servers (vanilla clients can join without installing any mod) and in singleplayer worlds.
- **Zero Dependencies**: Pure, minimal Fabric mixin.
